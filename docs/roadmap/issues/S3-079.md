# S3-079: Complete Mission CD campaign content

## Parent and ownership

Parent epic: https://github.com/stacksjs/the-settlers-iii-remake/issues/12
Source owner: `stacksjs/the-settlers-iii-remake`. Master roadmap: https://github.com/stacksjs/the-settlers-iii-remake/issues/4.

## Problem and observable result

Inventory every included expansion mission. Apply the correct edition rules. Verify progression and endings.

The current application is a browser prototype. Passing the Riverlands campaign does not establish original-game or native parity. This issue is complete only when its stated behavior has retained evidence.

Decoded mission data drives a bounded declarative objective runtime. Save mission progress with the world. Editing and import/export use the same validated map representation.
