Every settler walks. Every plank is carried.

A browser remake of The Settlers III Gold Edition, built on a deterministic simulation in which each settler, tool and good is a real object in the world. No production numbers are faked: if a carrier has not delivered the stone, the wall does not rise.

Run it locally Read the roadmap

A settlement that works the way it looks

Real logistics

Carriers fetch each plank and stone from where it lies, diggers level the site, and builders build from delivered material. Construction deliveries come before storage.

Tools and trades

Woodcutters need an axe, miners a pick, sawyers a saw. A workplace without its tool says so instead of hiring a phantom worker.

Soldiers and borders

Soldiers are recruited from carriers holding real weapons, garrison towers, fight and capture buildings. Pioneers push the border outward.

A computer rival

The rival surveys, expands, builds an economy and attacks through the same commands you use. Capture every enemy castle and tower to win.

Seeds and saves

Reuse a map seed for the same landscape. Settlements, seed and mission outcome survive save and reload on your device.

Keyboard first

Choosing a building moves the cursor to the nearest valid site and Enter places it. Dialogs contain focus and restore it when closed.

Where it stands

This is a faithful-remake effort, not a finished game. It does not yet reproduce the original promotions, other civilizations, ships, campaigns or measured timings. Each claim is tracked as a public issue with its evidence, and a feature is only marked done when its acceptance checks pass in a real browser.

  • 12 epics and more than 100 implementation issues, linked to the framework repositories that own each defect.
  • A fidelity audit that lists verified matches and known gaps.
  • Production browser acceptance runs on every push.

Original game media is not published here. Rights to redistribute it are unverified, so the public site carries no original art, sound or maps. You import your own copy of the free Amazons demo locally.

Build it yourself

bun install
bun run assets:import
./buddy dev frontend

Then open http://localhost:3000. Drag to pan, scroll to zoom, Space pauses, H centers on the castle and Escape cancels.
